# Olympic Men's Ice Hockey Dashboard (1992–2026)

## Project Overview

This Power BI dashboard analyzes the last 10 Men's Olympic Ice Hockey tournaments (1992–2026). The project focuses on team performance, medal achievements, top scorers, and goaltender statistics.

## Objectives

* Compare medal success across Olympic tournaments.
* Analyze historical performance of participating nations.
* Identify top scorers and goaltenders.
* Explore tournament results using interactive filters.

## Tools Used

* Power BI
* Power Query
* DAX
* Excel

## Data Sources

The dataset contains information about:

* Olympic medalists
* Team statistics
* Player scoring statistics
* Goaltender performance metrics
* Host cities and tournament stories

## Dashboard Pages

### 1. Nations Overview

* Medal distribution by country
* Historical medal rankings
* Tournament winner analysis
* Olympic tournament stories

### 2. Scorers

* Top goal scorers
* Assist leaders
* Points leaders
* Interactive filtering by year and country

### 3. Goaltenders

* Save percentage
* Goals Against Average (GAA)
* Wins and shutouts
* Minimum playing time filters for statistical relevance

## Key Features

* Interactive filtering by year and country
* Dynamic KPI cards
* Historical and tournament-specific insights
* Olympic storytelling component
